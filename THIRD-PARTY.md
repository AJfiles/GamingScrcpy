# Third-party components

Every item below is either fetched at build time by `tools/vendor-bootstrap.sh` or
already excluded from git; none of it is redistributed inside this repository's
source tree. The column that matters most is **Where it comes from**, because that
is what a rebuild must be able to reproduce.

| Component | Licence | How it reaches a build | Notes |
|---|---|---|---|
| scrcpy (upstream) | Apache-2.0 | this repo **is** a fork of it at tag `v5.0.1` | base commit `a60891a`; see `NOTICE` |
| `scrcpy-server.jar` | Apache-2.0 | built from `server/` in this tree | copied to the device by scrcpy itself — that is upstream behaviour, not an `adb push` |
| Android platform-tools (`adb.exe`, `AdbWinApi.dll`, `AdbWinUsbApi.dll`) | Apache-2.0 (Google) | `tools/vendor-bootstrap.sh` → `tools/platform-tools/` | was committed here as `tools/platform-tools.zip` (8,044,989 B); removed from git on purpose |
| stock scrcpy release (reference build) | Apache-2.0 | `tools/vendor-bootstrap.sh` → `tools/stock/` | was `tools/scrcpy-stock.zip` (11,264,634 B); nothing in the gate reads it any more — the §25 control uses `notepad.exe` |
| SDL2 | zlib | linked by the scrcpy client at build time (MSYS2 package) | render backends measured in `BUILD_REPORT.md` §5 |
| FFmpeg libraries | LGPL-2.1+ (as packaged by MSYS2/Revistock) | runtime DLLs next to `scrcpy.exe` in the packaged folder | LGPL means the app must let the user swap them — they are loose DLLs in the ZIP, which satisfies that |
| Inter | SIL Open Font License 1.1 | **not packaged yet**: downloaded under `out/fonts/` | the OFL text is `out/fonts/inter/LICENSE.txt`; packaging it into `launcher/Assets/Fonts/` is scheduled in directive v5 §2.1 |
| JetBrains Mono | SIL Open Font License 1.1 | **not packaged yet**: `out/fonts/jbmono/` | OFL text is `out/fonts/jbmono/OFL.txt` |
| Lucide icon geometry | ISC | icons in `launcher/MainWindow.xaml` are drawn as XAML `Path` data | re-confirm the upstream notice text before going public; this row is a claim about origin, not a verified licence text copy |
| `launcher/Assets/app.ico` | ours | generated by `tools/make_app_icon.ps1` | 7 resolutions, 16…256 px, asserted by the packaged self-test |

## What is deliberately not here

- `dist/`, `out/` and `workspace/` are machine-local: build output, measurement logs
  and the nested clone. `tools/publish_manifest.txt` is the authoritative list of
  what a release may contain, and `tools/publish_audit.sh` fails the build if the
  git index drifts from it.
- The 126 MB archive (`GamingScrcpy-win64-fork.zip`) is a **Release asset**, never a
  commit — GitHub refuses files over 100 MB, and `Compress-Archive` deletes its
  destination before it can fail, which is why packaging stages to a temp path first.
- Device serials and this machine's absolute paths are scrubbed from published text;
  the alias key lives in `out/publish/` precisely so it cannot be published. See
  `PROVENANCE.md`.
